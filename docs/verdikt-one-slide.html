What we built
AI-in · reviewable

Models read and decide

  • Ingest reads attachments into the program's own field schema
  • Triage classifies and routes; refills skip the verdict
  • Retrieve finds the rules that apply, by embedding
  • Verdict: approve, deny or missing info, with the rule cited
  • Every model call has a fallback and an audit entry
Deterministic-out

Code writes the reply

  • Frozen templates: human-approved, versioned, hashed
  • Merged, not generated: no model on the render path
  • Reply package: the letter plus the enclosures that outcome needs
  • Boundary test fails the build if render imports the AI layer
  • Reproducible: template version and render fingerprint on record
People and control

Humans on exceptions

  • Pipeline view: each stage's output, highlighted on the source PDF
  • Approve or reject a held reply before it leaves
  • Rules library: human-authored and versioned
  • Programs as data: a new program needs no build
  • Tenant scoping, roles, signed idempotent webhooks
