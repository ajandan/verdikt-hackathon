Criterion 01 / 04covered

Technological Implementation

“How well is the project built, and how effectively does it use Nebius Token Factory or AI Cloud model(s), and NVIDIA Nemotron as part of the solution?”
  • Five models on Nebius Token Factory, three of them NVIDIA: MiniCPM-V reads scanned intake and Nemotron-3.5-Super-VL cross-checks the read, Nemotron Nano triages, Qwen3-Embedding retrieves the rules, Nemotron Super reasons over any rule without a deterministic formula.
  • Nemotron stops at a hard boundary: the reply letter and JSON verdict are written by deterministic Python from typed models.
  • A boundary test fails the build if an LLM ever leaks into the render path.
Criterion 02 / 04covered

Design

“Does the project deliver a complete, coherent product experience not just a technical proof of concept?”
  • A working product, not a notebook. Fax, scanned paper and portal submissions fan into one email intake bus.
  • Each case ends in a reply letter from a frozen, human-approved template plus a JSON verdict a call-center system can act on immediately.
  • Eight live dashboards and Prometheus /metrics show an operator what's stuck and where the load comes from.
Criterion 03 / 04covered

Potential Impact

“Does the project make a credible, specific case for solving a real problem for a real audience and does the solution actually address it based on what's demonstrated?”
  • Patient Assistance Programs are one instance of a class: regulated document workflows where the letter that leaves the building is the audit artifact.
  • Prior authorization, benefit verification, informed consent and MedWatch reporting share the same shape and the same failure mode.
  • The demo runs one program end to end. A second program is a data change (rulebook plus templates), not a build.
Criterion 04 / 04covered

Quality of the Idea

“Is this a creative, non-obvious use of Nebius Token Factory or AI Cloud model(s), and NVIDIA Nemotron and does the team show genuine understanding of the problem space?”
  • Most document-generation entries put a language model on the artifact path. Verdikt refuses.
  • Models read, triage and rank; Nemotron reasons only where a rule needs judgment; deterministic code decides and writes.
  • The EU AI Act treats healthcare eligibility decisions as high-risk and demands the reproducibility Verdikt provides mechanically.
