About

Same idea. Better tools.

I built the first version of this in 2020. It took years of platform work and a new generation of AI tools before I could finally keep humans on the decision, not on the transcription.

The arc

Five stops, one idea

Same idea, resurfaced with better tools. Through-line: AI reads, deterministic code writes, humans decide.

2020
Stop 01 · The seed

Won a platform hackathon

A REST API for document generation. One endpoint. One document. No rendering logic in the caller. The interesting problem was content assembly, not delivery.

Then
Stop 02 · In the wild

Productionised inside a real engagement

Same idea, real business users touching it daily. Every mapping, every content branch was still defined by hand. Humans in the loop everywhere.

AI era
Stop 03 · The rebrush

Back to hands-on

Brushed up React on the front. Got fluent with LLMs, agents, RAG, retrieval, rerankers. Earned the right to design AI in, not bolt it on.

Quire
Stop 04 · Off-platform

The advanced version of 2020

Rebuilt outside any single platform. AI now carries the upstream human steps (mapping, extraction, verdicting). Deterministic code still owns the artifact.

2026
Stop 05 · This build

Verdikt, shaped for the rulebook

Nemotron on Nebius Token Factory for reasoning. A vision-language OCR for the read. Deterministic Python for the render. A paper-stamp verdict as the artifact.

Why this domain

Why PAP

Real letters. Real deadlines. Real humans stuck between a payer, a physician, and a patient, waiting on a decision a case-management team has to justify line by line.

Chat is not the product. A signed, auditable verdict is.

What carried over

Four habits from workflow-platform work

01

Case flow first

Every screen, every endpoint, every prompt has to move a real case toward a decision. If it doesn't, it doesn't ship.

02

Audit, not demo

Deterministic renders. Version-frozen artifacts. Byte-identical replays months later. Anything less isn't done.

03

AI on the read path

Extracts, classifies, retrieves, reasons. Never composes the final artifact. The separation is enforced by tests.

04

Ship the seam

The caller sees one clean endpoint. Whatever's underneath is my problem, not theirs.
