Claude Desktop MCP configuration

Paste this into claude_desktop_config.json to expose this tenant's templates and render tools to Claude Desktop. Uses mcp-remote to bridge Claude Desktop's stdio transport to our streamable-HTTP endpoint. 

{
  "mcpServers": {
    "{{ mcp_server_name }}": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "{{ mcp_url }}",
        "--header",
        "Authorization:${QUIRE_AUTH_HEADER}"
      ],
      "env": {
        "QUIRE_AUTH_HEADER": "Bearer {% if new_key %}{{ new_key }}{% else %}{% endif %}"
      }
    }
  }
}
