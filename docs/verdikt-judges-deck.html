01 · The problem

The decision is small. The reading is what takes days.

A patient-assistance application is a stack of four documents. Every hand-off in the chain opens all four again.

01

Enrollment form

Identity, household size, income attestation, consent.

02

Income proof

Pay stubs or a tax return, checked against the program's cap.

03

Insurance card

No coverage, or a denial for this exact drug.

04

Prescription

Prescriber, NPI, dosage and refills.

Intake, eligibility, fulfillment and compliance each re-read the same PDFs. That re-reading is the cost Verdikt removes.

02 · The idea

Draw the line where the trust requirement changes.

Reading may be wrong, so it stays reviewable. Writing must be reproducible, so it never touches a model.

AI reads

04 · How it works

Three steps, one endpoint.

① Read

The models read

  • Ingest: MiniCPM-V reads attachments into the program's field schema
  • Triage: Nemotron Nano classifies and routes; a rule-based classifier is the fallback
② Decide

The rules decide

  • Retrieve: Qwen3-Embedding finds the rules that apply
  • Verdict: Nemotron Super returns approve, deny or missing info
  • Every verdict cites the rule that fired
③ Deliver · remember

The template writes

  • A frozen, human-approved template merged with the verdict
  • No model on the render path
  • One audit entry per stage, with template hash and render fingerprint

Models run on one Nebius endpoint. Rules are human-authored and versioned. Templates are frozen before they can render.

09 · Business value

Where the value comes from, and how to measure it.

Demonstrated
  • Every verdict cites the rule that fired
  • Refills skip the verdict entirely
  • The reply is merged, never generated
  • A second program runs on the same code
By design
  • A new program is configuration, not a build
  • A new channel is one adapter
  • Models swap per program
  • Replies are reproducible and auditable
To measure in a pilot
  • [__]% of cases a reviewer re-opens the source PDF
  • [__] median time from receipt to verdict
  • [__] cost per case

The pattern generalizes: prior authorization, benefit verification, informed consent and safety reporting share the same shape, a regulated letter that is also the audit artifact.
