Aggregate

Ship signal

The dashboards below all render a paper-stamp verdict. This card is the aggregate: approved only when every downstream verdict is green. Production readiness is tracked separately since it's an operational status, not a ship-review gate.

The stamp mirrors Verdikt's real product output. Same shape for every case Verdikt decides: verdict word, four meta fields, paper texture, wax-stamp accent. Consistency is the point.

How to run this locally

Serve the folder

These pages fetch JSON with fetch(), which browsers block over file://. Serve reports/ over HTTP.

Local server
  • python -m http.server 8765 --directory reports (then visit http://localhost:8765/)
  • Rebuild test JSON: python reports/_gen_dashboard.py after a fresh pytest run
  • Rebuild feature/code/security JSON: hand-edit. They're grounded in docs/roadmap.md and the ADRs, not scraped
