How this works

The auto-mapper runs three passes over each @field in the source rule:

  1. Exact — source name matches a target slot 1:1.
  2. Fuzzy — strip form-vocabulary prefixes / suffixes, compare on the meaningful tokens.
  3. Unresolved — no confident match; you pick one from the dropdown.

Every row is editable — the algorithm is a hint, not a decision. On save, references in the criterion / exception text are rewritten to the target slot names and the new rule is scoped to the target program.
