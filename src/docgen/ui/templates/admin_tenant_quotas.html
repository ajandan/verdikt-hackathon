How enforcement works

The /render and /render/mapped API endpoints and the UI render form check renders per day before enqueueing a job. Over-cap requests return 429 with a body naming the tripped quota and its current usage.

Idempotent replays (an Idempotency-Key matching an earlier request) return the cached response and do not re-consume quota.

Active templates

Checked when a template is uploaded via the UI. To free capacity without deleting, deactivate an existing template on its detail page.
