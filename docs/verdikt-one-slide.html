A decision pipeline for regulated document workflows. Every verdict cites the rule that fired, and the reply that leaves the building is never written by a model.

AI reads

02 · DETERMINISTIC-OUT

Code writes

The reply is merged from a frozen, human-approved template. No model on the render path, enforced by a build-time test.

03 · PEOPLE

Humans decide

A reviewer sees every stage in the pipeline view, then approves or rejects a held reply before it leaves.
