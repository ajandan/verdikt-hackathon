The wedge for 2026

Agents can generate documents.
They can't be trusted to author them.

AI reads the case. Human-authored rules decide the outcome. A frozen, human-approved template supplies the words. That's the shape of trustworthy agent output for the next five years, and the only shape a bank or a payer will sign off on.

Verdikt is the decision layer for that shape. Every stage's output is a structured artifact a reviewer can read: intake, retrieved rules with rerank scores, verdict with citations, rendered letter. Every reply is bound to a version_hash a human approved, on a tenant a human provisioned. Supervision path, not hot path.

Governance in the shape of a product

The decision ledger is the point.

Every case writes a row. Which program, which rules fired, which outcome, which letter, for which tenant, at which second, with which citations. Reproducible on demand. Discoverable in a subpoena. Boring in the good way.

  • ◆Row-level tenant_id scoping. CI-enforced. One code path, three transports (REST, MCP, admin UI).
  • ◆API-key auth per tenant. Keys are the trust boundary, not IP.
  • ◆Idempotent by fingerprint. Same case from the same caller returns the same decision. No duplicate letters in the wild.
  • ◆Draft → Freeze → Publish. No letter renders that a human didn't bless. No rule fires that a human didn't author.

Questions a compliance officer actually asks

Straight answers.

Is a model called at reply time?＋

No. The reply path is a deterministic template merge. No model, ever. Given the same frozen template and the same verdict, the output bytes are identical, forever. The boundary is enforced by a build-failing test, not a comment.

Where does the AI actually run?＋

Three stages, all in front of the reply: extract (vision reads the inbound case into structured intake slots), retrieve (rules matched by embedding + rerank against a versioned pack), and reason (structured verdict over the retrieved rules). Every stage's output is a structured artifact a reviewer can inspect.

How do I onboard a new program?＋

As data, not code. A row in the programs table carries the extraction schema, the rules pack, and the reply template. The OncoBridge cameo proves it: same code, opposite verdict, no new deployment.

Can an agent bypass the freeze step?＋

No. Replies require a frozen template and a versioned rules pack. An agent can hand off a case over MCP; it can't publish a template or edit a rule. Publish and freeze are admin-scoped.

How is multi-tenancy enforced?＋

Row-level tenant_id on every business table, API-key auth per tenant, subject-tag routing on inbound email, and a CI-enforced tenant-scope audit script that fails the build on any query that could cross a tenant boundary.

What does rollback actually do?＋

Repoints the "current" version to a prior frozen template. Nothing is re-decided, no drift is introduced, and prior version_hash values remain valid for reproducibility.
