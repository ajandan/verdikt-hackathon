Internal reference

The Verdikt design system.

Tokens, type, and components used across the product surface. The palette leans on two families (ink for paper stock, seal for the brand accent), one display serif, one utility mono, and one body sans. Everything else is composition.

03 · Actions

Buttons

Two sizes: default (12×20px, 14px) for CTAs, .btn-sm (8×14px, 13px) for header rows. All buttons lift 1px on hover; primary swaps to seal-500 to hint at brand.

08 · Inversion

Dark sections

Dark sections use --ink-900 as background, --ink-50 for body, and --seal-300 for accent italics. They break rhythm on long pages — use for wedges, final CTAs, or contrast anchors, not as default.

Agents can generate documents. They can't be trusted to author them.

AI reads the case. Human-authored rules decide the outcome. A frozen, human-approved template supplies the words.

10 · Content

Voice & rules

Short sentences. Plain words. Metadata in mono, display in serif, prose in sans. The reader is a compliance officer, not an engineer.

  • No em dashes. Sentence breaks become periods, list intros become colons, parenthetical asides use ( ). Titles use middot (·).
  • Past-participle for verdicts. Stamped artifacts read APPROVED / DENIED / HELD. JSON enums stay lowercase present-tense (approve, deny, missing_info).
  • No vendor names. No specific CRMs, case-management systems, or competitor products in body copy or JSON samples. Use generic schemes (crm://, casemgr://).
  • Verdikt is the product name. Python package remains pap_pipeline. Don't leak the internal name to end-users.
  • Hackathon claims must be true today. If deploy is deferred, say “runbook complete, VM comes up next” — not “deployed on Nebius.”
CSP nonce trap. On any template with nonce="{{ '{{ csp_nonce(request) }}' }}" on its <style> tag, browsers silently drop every style="" attribute. All styling must live in the nonce-scoped block as classes. No inline styles. Detected by grep -c 'style="' /tmp/landing.html approaching zero.
